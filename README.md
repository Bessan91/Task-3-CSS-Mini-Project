# Task 3 — CSS Mini Project

A responsive landing page built with **HTML5** and **CSS3**, designed as part of a front-end mini-project task.

🔗 **Live Demo:** [https://bessan91.github.io/Task-3-CSS-Mini-Project/](https://bessan91.github.io/Task-3-CSS-Mini-Project/)

---

## 📌 Sections Overview

- **Navbar & Hero Section:** Top navigation bar paired with a bold hero area, headline, and call-to-action.
- **Customer Favorite Section:** Showcase of featured/popular items with clean cards and visual hierarchy.
- **Our Story Section:** Editorial block introducing the brand story, mission, or background.
- **Promo Banner Section:** Highlighted promotional callout designed to draw user attention.
- **Footer Section:** Closing section with links, branding, and essential site info.

---

## ✨ What I Practiced

- Structuring a multi-section landing page cleanly
- Styling typography, colors, spacing, and alignment with CSS
- Building cohesive visual sections from top to bottom
- Deploying a static site with **GitHub Pages**
